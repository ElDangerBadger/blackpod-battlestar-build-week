# Synthetic investment review sources

Two initialized REPLAY mission fixtures provide retained JSON for challenge and
deadline-comparison tests. They were created with MissionStore initialization,
immutable artifact capture and a second snapshot; no domain stages ran.

- `mission-investment-challenge-evidence` contains invented fundamental and
  statistical samples dated October 12, 2026. Role labels and different artifacts
  do not prove source independence, real research or calibration.
- `mission-investment-outcome-evidence` contains invented future deadline points
  dated April 11, 2027: margin change -1.5, an invalidation case +0.5, and an
  explicitly missing value. They are mechanics fixtures, not actual outcomes,
  performance or trade P&L.

Every artifact is marked `SYNTHETIC_FIXTURE`. Requests, immutable revisions and
current pointers use the existing canonical schemas. Original hypothesis source
fixtures from Burst 2 remain unchanged. See `docs/INVESTMENT_REVIEW.md`.
